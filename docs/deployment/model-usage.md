# 模型接口、价格和用量

模型配置支持 OpenAI Chat Completions（对话补全接口）、OpenAI Responses（响应接口）、Anthropic Messages（消息接口）和 Gemini GenerateContent（内容生成接口）。管理员在“管理端 → 模型配置”中选择提供方协议，保存服务地址、密钥和模型能力。

自 0.4.1 起，已有引用、价格或调用记录的模型仍可编辑和删除，提供方的协议及地址也可修改。删除模型后，使用它的员工和对话需要重新选择模型；历史调用、价格及费用记录继续保留，可以重新添加同名配置。删除提供方前需先移除其下模型，提供方删除时会清空访问密钥。

| 协议 | 服务基础地址示例 |
| --- | --- |
| OpenAI 兼容 | `https://api.openai.com/v1` |
| OpenAI Responses | `https://api.openai.com/v1` |
| Anthropic | `https://api.anthropic.com` |
| Gemini | `https://generativelanguage.googleapis.com` |

兼容服务使用其实际地址。模型目录读取失败时仍可手工配置型号；目录返回的能力有限，输出长度、上下文长度、工具能力和思考选项需按服务说明填写。平台不根据型号名称猜测这些值。

Anthropic 可以按 Token（模型处理内容的计量单位）预算或自适应等级配置思考；Gemini 可以按预算或原生等级配置。启用某个思考强度选项前，需填写该选项对应的参数。Anthropic 自动缓存可选择 5 分钟或 1 小时；是否命中、创建多少缓存，以服务实际返回为准。DeepSeek 兼容服务可以在 OpenAI 协议下选择对应的用量格式。

只有模型明确不适用的计量项才应标记“不适用”。没有返回某个字段不等于它不存在，也不等于免费。

## 配置价格

在模型的更多操作中打开“价格配置”，可以从 models.dev 公开目录生成草稿，也可以手动填写币种、价格时区及普通输入、输出、缓存读取、缓存创建的单价。可以按每千或每百万 Token 输入，单位切换保留十进制精度。留空表示未配置；免费项目必须明确填写 `0`。

匹配到服务地址和模型编码时，页面显示来源服务商及单价，点击“一键配置价格”核对后即可生成草稿。没有匹配编码、使用自定义别名或转发服务时，点击“搜索并选择价格”，按名称、编码、服务商模糊搜索，也可用服务商筛选缩小范围；少量拼写遗漏不会阻止查找。选择来源不会修改原模型或连接配置。

[models.dev](https://models.dev) 的公开价格以美元、每百万 Token 表示。导入保留该币种、来源和取得时间，不自动换算成人民币。草稿包含标准文本价格，以及来源明确提供的、按输入长度划分的价格区间。来源未提供的项目保持未配置，不填零。缓存创建单价没有注明有效期时不导入，需要按使用情况在草稿中补充；忙闲时段、专属折扣、独立思考价格及音频价格不自动推算。

生成草稿后可以修改价格、预览计算结果，核对后再发布。目录更新不会自动改动已生成草稿或已发布价格，历史金额保持不变；公开价格可能与实际合同不同，应在发布前核对。目录暂时无法读取时仍可手动配置；若使用先前读取的数据，页面会说明未能更新并显示取得时间。

基础价格适用于标准服务的默认情况。“更多价格规则”支持：

- 按总输入量设置价格区间，包含下限，不包含上限。输入量落在该区间时，整次请求使用这条规则的价格。
- 按星期和当地时间选择时段，跨午夜的部分按次日计算。
- 仅在指定日期使用，或排除指定日期。使用日期例外时填写日历覆盖截止日期，到期后显示未计价，避免继续套用过期日历。
- 为不同服务档位配置完整价目；同优先级规则不能重叠，非标准档位不能只覆盖部分输入区间或时段。
- 为 Anthropic 的不同缓存创建有效期分别设置价格；没有细分价格时可以配置通用缓存创建价。

优先级数值越大，规则越先匹配。跨午夜的时段会拆成当日和次日两条规则，拆分后每个价格版本最多保存 100 条规则和 2000 条例外日期。平台不内置厂商报价或法定节假日；价格来源和核对时间可随草稿保存。

“计算预览”仅使用填写的模拟数量和时间，不发送模型请求。发布确认展示新旧价格及规则；确认后立即用于后续请求。已发布版本不能修改，调整时复制为新草稿。已经发出的调用和历史调用继续使用请求发送时的价格版本，修改价格不会重算历史费用。

例如，假设无缓存、普通输入每百万 2 元、输出每百万 8 元，输入 1000、输出 50 的金额为 `0.0024` 元。这是计算示例，不是厂商报价。

## 查询实际消耗

回复完成后，可从消息操作查看本轮模型用量；对话标题区域提供累计用量。“管理端 → 用量统计 → 模型用量”支持日期、模型和用户筛选。企业统计要求企业范围的用量查看权限；普通用户只能查看本人有权访问的对话记录。

缓存读取和缓存创建已经包含在全部输入中，思考已经包含在输出中，不能再次相加。Anthropic 原始输入不含缓存，平台会先合并再展示；Gemini 的提示输入和工具输入、候选输出和思考分别合并一次。详情保留适用的缓存有效期和思考明细。

一轮任务可能多次调用模型，例如模型在取得工具结果后继续回复、运行子智能体、执行工作流或整理对话内容。因此，整轮任务的用量可能高于最后一次回复的用量。金额按已发布价格计算；不同币种分开统计，不换汇，也不扣余额。原有执行次数和次数限制继续独立生效。

未配置价格的请求仍保存用量。服务未返回完整用量、存在不支持的计费项或价格缺失时，只展示已确认部分，完整金额保持空缺。明确为零、未返回和不适用分别显示。小额汇总不会被显示成零，详情保留精确金额。

企业日期查询最多 93 天，对话累计不受该限制。计算尚未完成时可刷新；对话用量弹窗只在需要继续计算时自动更新。

## 升级与运行

本次使用 AgentScope Java 2.0.4。Responses 使用官方扩展及 OpenAI Java 4.52.0，Anthropic 使用 2.52.0，Google Gen AI 使用 1.45.0；平台补充完整用量、原生签名保存及请求生命周期管理。

0.3.0 的数据库迁移新增七张价格和调用记录表，保留已有用户、模型和对话。升级前备份数据库及业务卷，不修改旧迁移、不清空数据，也不将旧对话补成零消耗。新协议连接建立后，旧版本后端不能完整处理这些连接；回退需先停止相关新请求，保留新增表和已有记录。

客户端在实际请求时创建，在结束、失败和取消时释放，不随空闲用户常驻。用量保存失败时保留有上限的待保存数据；未恢复前达到容量上限的新增请求会在发送前被拒绝，避免产生无法登记的消耗。重新计算费用只使用已保存的调用记录，不会再次调用模型。进程中断或厂商缺少最终用量时，平台统计不能代替厂商账单。

开发验证使用真实开发库连接模拟协议服务；没有配置某厂商的测试凭据时，不代表已经验证其真实服务的全部型号。服务可能有不同的能力、收费项目和访问条件，以所用提供方为准。
