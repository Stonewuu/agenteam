# 社区版的功能与接口

0.2.0 将共有能力与商业扩展分别提供。社区版保留首次初始化创建的唯一企业，现有完整版本数据按商业版迁移；不能把旧多企业数据库接到社区版后继续运行。当前拆分版本尚未正式发布，本文说明源码中的功能归属。

## 社区版提供的能力

社区版包含智能体、技能、插件、知识库、数据源、对话与工具执行、文件、待办和定时任务。企业成员、团队、资料维护、内置角色分配、企业和指定成员的资源授权、基础执行用量、对话与工具记录导出均保留。成员数量没有商业授权上限，服务器资源限制照常生效。

企业微信与飞书的应用设置、密钥维护、账号绑定、登录、通知发送与重试也属于社区版。配置步骤见[企业消息说明](../deployment/enterprise-messaging.md)。企业名称可以修改；企业被异常删除或停用不会重新开放初始化，也不会自动创建替代企业。

自定义角色写入、多企业创建、团队高级资源授权、组织次数规则、高级审计查询与导出、演示账号属于独立的商业扩展。社区版不安装这些控制器或页面；修改前端显示不能获得对应服务端能力。

## 接口契约与历史数据

[OpenAPI（接口描述格式）契约](../../agenteam-server/src/test/resources/contracts/openapi.json)列出社区当前接口，版本与前后端一致。身份和企业上下文中的 `capabilities`（当前账号可用操作）供界面显示入口，实际请求仍重新校验成员、权限、数据范围和当前业务状态。

测试附件中的 `schema-target.sql`、`data-model.json`、`permission-seed.sql` 和 `historical-permissions.json` 保存拆分前的完整目标结构及种子快照，用于检验历史数据库兼容。历史表或权限记录仍存在，不表示社区提供对应商业接口。生产升级使用运行资源中的 Flyway（数据库迁移执行工具）脚本，不执行这些测试附件。

已有数据库的迁移脚本名称和内容保持不变。新社区部署升级为商业版时保留部署编号、企业、成员、资源、任务及企业消息密钥；具体迁移步骤随商业版交付。商业版数据不支持直接降回社区版。
