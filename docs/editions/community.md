# 功能与接口参考

AgenTeam 将数字员工、知识与工具、项目文件和团队协作连接在同一工作空间中。完成初始化后，管理员可以配置模型服务、邀请成员，并为团队分配角色和资源访问权限。

## 工作空间中的能力

- **数字员工**：创建和发布智能体，组合技能、插件、知识库、数据源与外部工具，供成员雇佣使用。
- **对话与文件**：开展多轮对话、调用工具、协作处理任务，预览、下载和复用生成的文件。
- **团队协作**：维护企业资料、成员与团队，分配角色和资源访问权限，管理个人与团队待办。
- **计划与通知**：按一次性、每日、每周或每月规则执行任务、发送通知，并查询执行记录。
- **企业消息**：连接企业微信与飞书，完成账号绑定、平台登录和工作通知配置。
- **记录与用量**：查看执行用量，导出对话与工具记录。

[企业消息配置指南](../deployment/enterprise-messaging.md)介绍应用设置和成员绑定；[部署指南](../deployment/images.md)提供安装、配置及维护步骤。

## 接口与数据维护

[OpenAPI（接口描述格式）文件](../../agenteam-server/src/test/resources/contracts/openapi.json)列出当前接口。身份与企业上下文中的 `capabilities`（当前账号可用操作）可用于集成界面；服务端按成员身份、权限和业务状态处理请求。

数据库升级由 Flyway（数据库迁移工具）执行。更新部署前备份数据库、配置、应用密钥和业务文件，保留原有数据卷，并按当前版本的升级步骤操作。
